# Проект: Прогнозирование стоимости страховых выплат

## Описание проекта

Цель проекта — разработать модель машинного обучения для предсказания итоговой стоимости страхового возмещения (`UltimateIncurredClaimCost`) на основе характеристик работника и параметров страхового случая.

Задача является актуальной для страховых компаний, так как точная оценка будущих выплат позволяет формировать резервы, рассчитывать тарифы и снижать финансовые риски.

## Датасет

Используется датасет **Workers Compensation**, доступный через OpenML (ID: 42876).  
Он содержит 100 000 записей о страховых случаях с 14 признаками, включая:

### Признаки:
- `DateTimeOfAccident` — дата и время несчастного случая
- `DateReported` — дата сообщения о случае
- `Age` — возраст работника (от 13 до 76 лет)
- `Gender` — пол работника (M/F)
- `MaritalStatus` — семейное положение
- `DependentChildren` — количество детей на иждивении
- `DependentsOther` — количество других иждивенцев
- `WeeklyPay` — еженедельная зарплата
- `PartTimeFullTime` — тип занятости (Part Time/Full Time)
- `HoursWorkedPerWeek` — часов работы в неделю
- `DaysWorkedPerWeek` — дней работы в неделю
- `ClaimDescription` — описание заявки
- `InitialCaseEstimate` — начальная оценка стоимости случая

### Целевая переменная:
- `UltimateIncurredClaimCost` — итоговая стоимость страхового возмещения (варьируется от 20 до более 3 млн)

## Установка и запуск

1. Клонируйте репозиторий:
git clone https://github.com/Wasupit/workers_compensation_project.git
Перейдите в папку проекта:

cd workers_compensation_project
Установите зависимости:

pip install -r requirements.txt
Запустите приложение:

streamlit run app.py
